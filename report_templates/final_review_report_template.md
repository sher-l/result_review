## 临床统计项目附加段落（命中 01_baseline / 02_Logistic / 03_Nomogram / 04_ML_Modeling 时必写）

在“一、审核结论”或“六、详细问题与依据”中，至少明确回答以下 4 点：

1. 基线统计方向性是否正确。
2. Logistic 方法描述是否与代码一致。
3. 是否存在生存分析模板残留。
4. SHAP 是否交付数值导出表。

推荐句式：

- 基线方向性：已核对 / 存在反向描述（示例：报告写“胎数更高”，但基线表显示双胎率更低）。
- 方法-代码一致性：已核对 / 存在虚假方法声明（示例：报告写“逐步回归”，代码无 `step()` / `stepAIC()`）。
- 模板残留：已排除 / 仍发现“死亡风险”“不同时间结局”等生存分析术语。
- SHAP 证据：图件与数值均齐全 / 仅有图件，缺少数值导出。
