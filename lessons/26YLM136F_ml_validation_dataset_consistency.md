
# Lesson: 26YLM136F 机器学习验证队列一致性

适用范围：含多队列机器学习模型排名、平均 AUC/Accuracy/F1/Recall、外部验证集矩阵的报告审核。

触发信号：报告数据来源只列出部分 GSE/TCGA 队列，但模型评价矩阵列名出现额外队列。

审核动作：
1. 提取报告数据来源句中的队列名。
2. 提取 rawdata 目录和所有 *_mat.txt、AUC/Accuracy/F1/Recall 矩阵列名。
3. 复算报告平均值，分别记录“含全部列”和“排除未披露列”的排名。
4. 如果报告数值只在排除未披露列时成立，且纳入全部列会改变最优模型，按 CRITICAL 候选处理。

本案证据：26YLM136F 的 AUC_mat.txt 包含 GSE20916；报告未披露该队列；纳入后 Lasso+NaiveBayes 平均 AUC 约 0.965，排名第 57，不支持报告最优模型结论。
