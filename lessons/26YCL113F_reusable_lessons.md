# 26YCL113F 可复用审核经验

- 项目编号必须在目录、报告、工作流、关键模块和通知 manifest 中一致；若 Layer 0 已报 FATAL，P0 汇总不得显示通过。
- DEG 审核要同时检查 FDR、效应量阈值和实际效应量分布；“全体 FDR 显著基因”不能自动等同于 DEG 候选集。
- 多暴露 MR 必须以预定义主方法的全体结果做 FDR 校正；共定位不能补救 MR 初筛未校正造成的假阳性膨胀。
- 无代码/环境与 MD 缺少体系、轨迹和运行日志是两种独立可复现性风险，应分别列示修复动作。
- GSEA 的方向性要从排序向量、CSV 的 ES/NES、源图到正文逐层匹配；若不一致，要求重算或统一全部表达，而非仅修订文案。
