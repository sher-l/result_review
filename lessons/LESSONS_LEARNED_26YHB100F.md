# 26YHB100F 经验教训

## 结论

- 该项目暴露出的主要风险不是“结果文件缺失”，而是“结论方向、方法名称、模板残留和图件真伪”四类问题叠加。

## 关键教训

1. MR 不能只核对显著性，必须逐基因核对 OR 或 β 的方向。
   - 报告把 FASN、PTGS2、ACADS 写成保护因素，但 IVW OR 全部大于 1。
   - 审核时要直接查最终 MR 结果表，不能只看森林图配色或正文总结。

2. 机器学习方法名称必须和代码实现逐项对应。
   - glmnet 的 alpha=0.6 不是纯 LASSO。
   - rfeControl(functions = rfFuncs) 不是标准 SVM-RFE。
   - 还要核对进入模型的实际输入特征集，防止报告写“10 个基因直接进 SVM”，脚本却先做了额外筛选。

3. 单细胞章节必须强制做“错图/模板残留”双检查。
   - QC 前后图可能被错误复用为同一张图。
   - t-SNE/UMAP、Sham/MCAO 与 Control/NAFLD、Epithelial cells 与 Hepatocytes 等残留很容易混入终稿。
   - 这类问题不能靠关键词搜索替代，必须至少抽看关键图件。

4. MD 模块不能只看最终曲线图。
   - 方法段和结果段可能写出两套互相冲突的参数。
   - 若未交付 xvg/csv 等原始轨迹，曲线图本身不足以支持复核。

5. 对接模块要避免“误判为无定量结果”。
   - 本项目实际交付了结合能汇总表和对接结构图，但正文仍有图号残留。
   - 审核时既要抓证据不足，也要避免把已存在证据误判为缺失。
