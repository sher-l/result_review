# 26YHB399F 可复用审核教训

**适用范围**：多组学、单细胞/空间转录组、外部数据库 IHC/HPA、机器学习生物标志物报告。

1. **核心结论必须有可复核载体。** 报告中的 spot 数、QC、细胞比例、通信边、轨迹推断等不能只由 PDF 支撑。审核时建立“结论—表/对象/矩阵—路径—字段”闭环；无结构化载体的核心模块按高风险处理。
2. **把极值结论与源表排序逐项核对。** 对“最高、最低、Top、核心、显著”等词，必须比较声明对象与源表实际排序；若不一致，不得允许该对象继续作为下游分析锚点。
3. **追踪同一分析链的实体。** 对空间轨迹、细胞通讯和亚群分析，从方法到输入、图件、结果、结论抽取细胞/基因/队列实体；任何未说明的 FCN1+ Mac ↔ FN1+ TAM 类变更都应升级为实质性一致性问题。
4. **外部资源比较要保存元数据证据卡。** HPA/IHC 的疾病、组织、分组、抗体 ID 必须逐图记录；Normal/Tumor 只有在关键元数据匹配时才能被视为可比。
5. **数据集 accession 必须唯一映射到用途和本地输入。** 从报告正文、表格和 manifest 抽取编号；同一用途出现多个编号时，要求提供明确的角色说明与本地文件映射。
6. **图件校验同时检查编号和语义。** 需要检查正文图号—caption 一致性、图号唯一性、轴/图例与源表字段一致性。图存在不等于图表达正确。
7. **关键词目录匹配只能作候选，不能直接判错。** Monocle、CellChat、RCTD 等工具名常与模块目录名不同；需通过语义别名、目录功能和结果文件共同确认模块是否存在。
