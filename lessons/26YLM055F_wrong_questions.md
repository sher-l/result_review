# 26YLM055F wrong_question_set

## 1. 阈值写入报告但未进入实际导出

- 典型错误：报告写双阈值，代码只对最终输出应用其中一个阈值。
- 触发场景：TWAS、DEG、ROC等筛选脚本中出现过滤对象与导出对象不同。
- 证据基础：r.01.TWAS.R L113-L115；02.TWAS_significant_genes.csv。
- 正确标准：所有报告阈值必须在最终结构化输出中可复算。
- 下次提醒：检查变量名是否从filtered对象继续流入write.csv。
- 严重度：CRITICAL。
- 可执行规则建议：扫描“*_filtered <-”后续write.csv是否仍写未过滤对象。

## 2. 验证集上重选阈值冒充外部验证

- 典型错误：用验证集真实标签重新选择ROC/Youden阈值，再报告验证性能。
- 触发场景：confusion matrix、ROC、诊断模型小样本验证。
- 证据基础：r.15.1_gene.confusion.matrix.R L212-L237。
- 正确标准：验证集只能用训练集固定规则做一次性评估。
- 下次提醒：验证集脚本内出现coords(..., 'best')或按true_label计算趋势，应升级为MAJOR以上。
- 严重度：MAJOR。
- 可执行规则建议：检测test/validation代码块内是否调用roc/coords并生成阈值。

## 3. 最终特征基因与下游验证输入错位

- 典型错误：报告称验证机器学习最终基因，脚本实际读取上游Venn候选基因。
- 触发场景：多阶段pipeline中13.Venn、15_machine_learning、16.ROC等目录交错。
- 证据基础：r.16.3_gene.ROC.R L21,L96；03.ROC.past_gene.csv。
- 正确标准：每个下游验证脚本应读取上一步最终结构化输出。
- 下次提醒：核对报告最终名单与结构化通过名单是否完全一致。
- 严重度：CRITICAL。
- 可执行规则建议：比较报告最终基因集与ROC pass_gene表集合差异。

## 4. 高风险预测模块缺运行契约

- 典型错误：交付结果表存在，但缺脚本、输入、参数、版本、日志。
- 触发场景：scTenifoldKnk、药物预测、网络数据库、外部平台导出。
- 证据基础：script目录未见scTenifoldKnk脚本；r.20读取未交付D2D TSV。
- 正确标准：高风险模块必须能在交付包内定位输入、代码、参数和输出。
- 下次提醒：有临床转化/靶点/药物表述时，优先审查复现契约。
- 严重度：MAJOR。
- 可执行规则建议：高风险模块若缺脚本或关键输入文件，默认不得通过。
