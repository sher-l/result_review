# 可复用审核经验：证据链与跨载体一致性

1. 高风险计算主张按证据包审核：输入、版本/参数、执行记录、原始输出、分析结果缺一关键层，即限制为探索性，不能称验证、因果或研发依据。
2. 终表、PDF 和截图只证明展示结果，不证明可复现；在线工具也应保留提交输入、版本/作业标识、参数和原始返回。
3. 对疾病、数据集、分组、基因、图号、面板、样本量和路径建立跨正文、图、表、文件名与目录的实体一致性检查；一次标签残留应触发同模块同类实体的扩展核对。
4. 图号检查须覆盖全局唯一性、连续性，以及正文—图注—面板—源资产的一对一映射；格式正确不足以证明可追溯。
5. 统计主张应有可机读的 FDR、筛选阈值、CV 元数据和逐队列性能指标；不能从图像单独推断统计有效性。
6. 视觉审核应分离覆盖、科研语境、可读性和科学有效性。装饰或宣传资产需明确分类，覆盖闭合不等于没有问题或结论通过。
