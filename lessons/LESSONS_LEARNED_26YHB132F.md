# LESSONS_LEARNED_26YHB132F

## 案例摘要

项目：26YHB132F。主题：多组学、单细胞、空间转录组、MR、共定位、分子对接和MD探索骨关节炎与Mitoxyperilysis相关机制。最终审核结论为不合格，核心原因是数据集身份冲突、原始单细胞源缺失、全流程无代码、共定位阈值不支持阳性结论，以及高风险对接/MD模块不可复现。

## 错题 1：同一句数据来源内出现两个GSE编号

- 错误类型：数据集身份错写 / copy-paste残留。
- 具体表现：报告称“转录组数据数据集GSE89408”，同句又写“下载GSE12452数据集”。
- 触发场景：材料方法的数据来源段，尤其是“数据集A：下载数据集B”这种句式。
- 证据依据：`report_text.txt:12`；交付rawdata为`GSE89408_raw_counts_GRCh38.p13_NCBI.tsv.gz`，未见GSE12452原始文件。
- 正确标准：正文数据集编号、rawdata文件名、平台、样本量和下游结果文件必须一致。
- 下次审核提醒：全文提取所有GSE编号后，与`00_rawdata`和结果文件反向比对；同一句出现两个GSE时优先按CRITICAL处理。
- 严重程度：CRITICAL。

## 错题 2：单细胞原始数据源未交付但下游结果完整

- 错误类型：数据流断裂。
- 具体表现：报告声明GSE253198为单细胞来源，交付目录只有处理后`01_scRNA`结果和空间GSE253199原始数据，未见GSE253198原始矩阵或样本元数据。
- 触发场景：单细胞/空间联合分析中，rawdata只保留空间切片而遗漏单细胞参考。
- 证据依据：`report_text.txt:15`声明GSE253198；`00_rawdata`仅见GSE89408、GSE283079、GSE253199相关源文件。
- 正确标准：scRNA主数据集必须交付原始矩阵、元数据和从原始数据到对象的处理脚本。
- 下次审核提醒：不要只看`01_scRNA`结果是否丰富；必须从`00_rawdata`反向追踪到每个声明的数据集。
- 严重程度：CRITICAL。

## 错题 3：共定位阈值写明但结果未达到仍暗示阳性

- 错误类型：阈值-结论不一致。
- 具体表现：报告声明PPH4>0.70支持共定位，但展示和结构化结果最高PP.H4.abf仅0.542572576；同时表格把多个eqtl-a-ENSG条目统一写成TFRC。
- 触发场景：MR后续coloc模块，报告复制模板表格或只保留目标基因名。
- 证据依据：`report_text.txt:337-357`；`21_coloc/coloc_summary.csv`。
- 正确标准：不满足预设阈值时必须写“未发现支持共定位的证据”或按实际后验概率谨慎表述；表格基因标签必须来自结构化结果。
- 下次审核提醒：对coloc优先计算`max(PP.H4.abf)`并与报告阈值比对，再核对gene/eQTL列是否被统一替换。
- 严重程度：CRITICAL。

## 错题 4：高风险模块有图片和输出但缺脚本参数闭环

- 错误类型：高风险模块不可复现。
- 具体表现：分子对接有结合能表和complex.pdb，MD有xvg输出，但无对接/MD脚本、软件命令、grid/力场/拓扑/模拟参数等闭环材料。
- 触发场景：药物预测后追加对接和MD模块，结果图多但运行配置少。
- 证据依据：`project_structure.json`显示`total_code_files=0`；`mechanical_check_result.json`的MC-016；`25_docking`、`26.Dynamic`仅可证明存在输出。
- 正确标准：对接和MD至少应有输入、参数、脚本/命令、软件版本、阈值解释、结构化输出和图像证据。
- 下次审核提醒：不能因PDB、xvg、曲线图存在就判为充分；高风险模块需单独按“存在、证据充分、可复现、结论不过度”四格判定。
- 严重程度：CRITICAL。

## 错题 5：机械检查假阳性必须处置而不能照抄

- 错误类型：机械结果AI处置不足。
- 具体表现：Cancer仅出现在参考文献/通路名语境，不是正文模板残留；GSE253199在正文已明确提及；药物预测目录虽未含Drug关键词但实为`23_CTD`和`24_TCM`。
- 触发场景：机械检查按关键词或目录命名粗匹配。
- 证据依据：`report_text.txt:16,427,440`；`23_CTD`和`24_TCM`目录存在。
- 正确标准：机械问题必须逐条AI处置为保留、撤销、降级或升级，并写明证据依据。
- 下次审核提醒：保留真正阻断项，同时撤销参考文献/通路名/目录命名造成的误报，避免最终报告噪声过高。
- 严重程度：WARNING到MAJOR。
