# 26YSH042F 可复用审核经验

## 可复用模式

1. **项目身份三方核验必须前置**：报告中任一外来项目编号与 manifest/目录不一致即为 FATAL；同一根因应跨切片去重，不重复计数。
2. **图号与视觉审核均需闭环**：全局 Figure 编号、标题和正文引用要可一一定位；被分派的人工视觉队列必须记录 `pass/fail/not-assessable`，机器无 flag 不等于审核完成。
3. **药物与富集结论要做字段级检查**：规则名称、阈值、TopN、结果表、图示对象和方向字段必须一致。GSEA 方向须由比较组和 NES/ES 支持，不能由曲线形状决定。
4. **高风险计算不可只交付展示物**：对接、MD、虚拟敲除应交付输入、参数/命令、版本、日志、原始输出及图件映射；单次计算只能称为计算观察，不能替代独立验证。
5. **模型性能必须分层陈述**：外部判别、校准、阈值分类、决策效用及 endpoint label 需分别核验；训练图或 AUC 不能单独支撑“外部诊断性能良好”。
6. **极小基因集富集仅能探索性解读**：单基因驱动的 term 及正文/图注/对象数冲突均应限制机制或治疗外推。
7. **PDF 图件不是结构化证据**：单细胞显著性、拟时序、ROC/CI、ANN、列线图均应交付可核对的数值表、模型参数与计算上下文。
8. **参考文献用途需可追溯**：疾病特异性文献被标为数据/基因集来源时须与项目主题核验；标题不符本身不等于数据混入。

## 建议纳入框架的最小规则

- `report_project_id == case_manifest.project_id == project_structure.metadata.project_id`，否则 FATAL。
- required 视觉队列不存在 TODO/空 Finding/空 Severity 后才可完成。
- 高风险模块缺少脚本或命令、输入、参数、日志、原始输出任一项时，标注“不可端到端复现”。
- 含 GSEA 方向结论时必须同时存在比较方向和 NES/ES（或等价字段）。
- 机器学习“外部验证”必须有外部标签、预测、校准证据与正确 endpoint label；否则禁止扩展为诊断效用结论。
