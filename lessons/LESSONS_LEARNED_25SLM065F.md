# 25SLM065F 审核错题集

## 错误类型 1：正式结果报告混入方案项目编号

- 具体表现：目标项目为 25SLM065F，但正式结果报告封面“单号”为 24SLM440F。
- 触发场景：zip 内同时存在方案设计 docx 和正式结果报告 docx，方案编号可能残留到结果报告封面。
- 证据依据：`result_review_report/25SLM065F/report_text.txt` L6。
- 正确标准：正式结果报告封面、文件名、case_manifest 项目编号必须一致。
- 下次审核提醒：用户提示“方案设计仅供参考”时，仍需核对正式报告内部是否残留方案编号。
- 严重程度：FATAL。

## 错误类型 2：药物预测交集未按唯一 Chemical ID 复核

- 具体表现：报告称三基因 CTD 交集只有 bisphenol A，实际三个 xlsx 按唯一 Chemical ID 求交为 8 个。
- 触发场景：CTD 导出表同一药物可能有多条 interaction；若只按图或手工筛选，容易漏掉交集药物。
- 证据依据：`附件/3.15药物预测与分子对接结果/drug/CTD_*.xlsx`。
- 正确标准：先在每个基因表内按 Chemical ID 去重，再求交；任何额外筛选条件必须写入方法。
- 下次审核提醒：药物预测模块优先核对唯一 ID 交集，而不是只读正文药物数。
- 严重程度：CRITICAL。

## 错误类型 3：机器学习最佳模型把训练集混入验证集平均

- 具体表现：报告方法称按验证集平均 AUC 选择最佳模型，但所选 Stepglm[backward]+GBM 只有把训练集一起平均才为 0.72；验证集平均低于 NaiveBayes。
- 触发场景：诊断模型热图同时展示 Train 和验证集，平均列口径未说明。
- 证据依据：`附件/3.7诊断模型结果/AUC_mat.txt`。
- 正确标准：方法段定义的选择规则必须与实际计算一致；训练集性能不能混入“验证集平均”而不说明。
- 下次审核提醒：遇到“最佳平均 AUC”必须分别计算验证集平均和全数据平均。
- 严重程度：CRITICAL。

## 错误类型 4：分子对接只有展示图无打分证据

- 具体表现：报告给出结合能，但交付目录缺 Vina 日志、结合能表、grid 参数和脚本。
- 触发场景：分子对接结果只交 PyMOL 图和 PDB，未交 docking 原始输出。
- 证据依据：`附件/3.15药物预测与分子对接结果/` 与 MC-016。
- 正确标准：分子对接需至少交付对接参数、Vina 输出、结合能汇总表和可复现脚本。
- 下次审核提醒：不要因有 PDB/PDF 图件就判定对接结论成立。
- 严重程度：CRITICAL。
