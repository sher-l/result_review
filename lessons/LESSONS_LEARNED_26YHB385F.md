# LESSONS_LEARNED_26YHB385F

- 代谢组差异表同时含 P-VALUE 与 Q-VALUE 时，必须分别统计 P 口径和 Q 口径通过数；报告数量若等于全表或 P 口径，不能默认满足 Q 口径。
- 单细胞组间结论必须核查生物学重复数；只有 n_cells 和 Wilcoxon/p_adj 的细胞级证据不能直接支撑供体组差异。
- docking/MD 仅交 PDF 或少量汇总表时，只能证明存在展示图，不能证明 pose、轨迹、参数和稳定性结论可复核。
- 物种项目使用 Homo sapiens (SMPDB) 等跨物种数据库时，必须要求映射说明和局限，否则按体系一致性问题记录。
- 参考文献区的外项目疾病/肿瘤/药物关键词也会影响报告可信度，不能因为位于文末而跳过。
