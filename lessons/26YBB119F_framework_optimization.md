# 26YBB119F framework_optimization_notes

## 需要加强的规则

1. 列线图/预测模型高风险规则：当 AUC=1、Sensitivity=1、Specificity=1 或 OR CI 出现 0/Inf，且无外部验证、交叉验证或过拟合披露时，应自动生成 CRITICAL 候选。
2. 总结段逐句回溯规则：最终总结中出现的通路、细胞类型、靶点开发、机制表述必须在结果表或正文中有对应证据。
3. 结构化中间证据规则：PPI、机器学习、ROC、生存、单细胞表达、虚拟敲除需要各自 minimum_table_set；只有 PDF 图时不得判定证据充分。
4. 机械模板残留规则：癌症项目中 Tumor/Cancer 应进入上下文 AI处置；不应直接作为 CRITICAL。
5. subagent 切片规则：高风险模块、图文一致性、统计证据充分性应保持第一层并行切片，本项目 8 个切片有效降低遗漏风险。

## 无需改变的规则

- 代码未交付单独不升级为 CRITICAL 的规则仍适用；本项目将其作为 WARNING，同时把由此导致的具体证据链缺口分别归入 MAJOR。
- 企业微信禁止测试/非正式发送规则仍适用；本项目只使用飞书通知。
