# 26YZY134F 可复用审核经验

* 外来项目 ID 必须先区分可执行路径与注释残留；注释残留通常是代码卫生问题，除非存在执行调用链。
* scRNA 的少量供体设计不能把细胞级 Wilcoxon 当作供体级推断；审核应联查样本数、身份设置和模型。
* 多候选 MR 应核验报告候选数、代码输入、结果 exposure、全局多重校正和 Steiger 等敏感性脚本是否形成可重建链。
* 高维虚拟敲除需多重比较控制；区域共定位必须区分区域 `PP.H4.abf` 与单 SNP `SNP.PP.H4`。
* 关键模块只交付 PDF 时，应要求对象、数值表、阈值与统计；视觉预筛不等同于正式图形审核闭环。
