# 26YSH061F 错题集

## 错题 1：未交付对象被写成最优对接结果

- 错误类型：图文表三方不一致 / 外项目或未交付药物残留
- 具体表现：正文写 IL6-PONATINIB 结合能最低，但图件和结合能表均无 PONATINIB。
- 触发场景：分子对接模块列出多组候选药物并声称最低值、最优值。
- 证据依据：Figure 8 A-C、结合能.xlsx、8_Docking 三个子目录。
- 正确标准：最低值必须来自同一结构化结果表，且图注、正文、目录均一致。
- 下次审核提醒：搜索“最低、最高、Top、best、PONATINIB”等排序词并反查表格。
- 严重程度：CRITICAL。
- 可执行规则建议：新增高风险模块规则：对接最低值对象必须出现在结合能表和图件标题中。

## 错题 2：药物筛选 TopN 未说明限定范围

- 错误类型：TopN 规则不透明
- 具体表现：报告称按 interaction score 排序选 3 对 IL6 药物，但全表 TopN 并非这些关系，同分项未解释。
- 触发场景：DGIdb/DrugBank/CTD 等候选药物结果二次筛选。
- 证据依据：DGIdb.csv 过滤后 23 条记录。
- 正确标准：必须说明先限定靶点、再排序、同分处理和排除规则。
- 下次审核提醒：不要只核对被选中对象存在，要核对未被选中的更高分对象。
- 严重程度：CRITICAL/MAJOR，视是否影响后续主线。
- 可执行规则建议：药物预测审核 prompt 增加“全表 TopN vs 限定靶点 TopN”双排序检查。

## 错题 3：高风险 MD 只交付后处理图却写强稳定性结论

- 错误类型：证据等级外推
- 具体表现：只有 xvg/PDF 曲线，缺少 mdp/top/tpr/xtc/log/QC，却写“达到动态平衡、稳定性良好”。
- 触发场景：Gromacs/AMBER/MD 模拟模块。
- 证据依据：9_Dynamic 目录仅有 4 个 xvg 与 4 个 PDF。
- 正确标准：强稳定性结论需要轨迹、参数、平衡、温压/能量 QC 或明确限制。
- 下次审核提醒：检查 mdp、top、tpr、xtc/trr、log、edr 是否存在。
- 严重程度：MAJOR。
- 可执行规则建议：MD 模块缺复跑材料时自动提示降级结论。
