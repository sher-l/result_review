# 26YYH159F 可复用审核经验

## 可复用模式

1. **交付脚本与结果并存不代表可复现**：应静态解析脚本I/O并逐个核对交付包内的输入、中间文件和路径映射。
2. **高风险MD需区分“曲线存在”与“可独立复跑”**：XVG/PDF只能支持结果阅读，不能替代轨迹、拓扑、tpr/mdp、参数、日志和脚本。
3. **方法声明应按字段级映射代码**：例如Protein Coding筛选必须有相应的`Type/Category`条件，不能仅以分值阈值替代。
4. **图号解析必须保留子编号**：`Figure 9`、`Figure 9-1`与`Figure 9-2`是不同键，不能按整数前缀去重。
5. **富集报告应披露映射损失**：上游候选基因数与`GeneRatio`分母不同，需报告输入、映射成功及未映射数量。
6. **GGI/GeneMANIA网络图不能替代结构化网络证据**：当报告解释具体互作类别、边或功能时，应交付节点—边、关系类型/权重或CYS/SIF/GraphML等工程/导出；仅PDF时只能支持展示性阅读，不能结构化审计，此类证据不足按WARNING处理。
