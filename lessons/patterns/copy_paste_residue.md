# 模式：Copy-Paste 残留

> 严重性：🔴 FATAL — 审核中最高频、最致命的问题类别
> 涉及项目：25YLC105F, 25YYF085F, 25YZF106F, 26YHB147F, 26YLM076F, 26YSH015F, 26YYS083F

---

## P01: 项目编号残留

**描述**：从其他项目复制报告/代码时未修改的项目编号、setwd 路径、标题编号。

**信号**：
- setwd/工作目录中的项目编号≠实际项目
- Word 报告首页"单号"与项目编号不符
- 代码注释中的项目编号不匹配

**检测**：`check_project_id_consistency.py` 自动扫描

**案例**：26YYS083F 首页写"26YYS056F"

---

## P02: 疾病名称残留

**描述**：从其他疾病项目复制报告时遗留的错误疾病名。

**信号**：
- NAFLD 残留在肾结石项目
- HCC 残留在胰腺癌(PAAD)项目
- Tumor/Normal 术语出现在非癌症项目
- 不相关的细胞类型（如视锥细胞出现在心肌病项目）

**检测**：`check_term_consistency.py` + 全文搜索常见癌种缩写列表 (HCC/PAAD/LSCC/LIHC/LUAD/BRCA/KIRC/GBM)

**案例**：26YYS083F 预后分析段写"与HCC患者不良预后"（本项目为PAAD）

---

## P03: 数据集/路径编号残留

**描述**：报告或代码中出现不属于本项目的 GEO 编号、文件路径引用。

**信号**：
- 正文提到的 GSE 编号不在 01_Rawdata 目录
- "文件夹 04_exp_XXX"但该文件夹不存在
- 参考文献的数据集 vs 本研究数据集混淆

**检测**：提取全部 `GSE\d+` → 与 01_Rawdata 交叉验证；全文搜索"文件夹""目录" → 验证路径存在性

**案例**：25YYF085F 出现"04_exp_RNF138"路径（来自其他项目）

---

## P12: 特定章节模板残留

**描述**：某些高复用章节（CellChat、SHAP、DCA、生存分析）整段复制残留错误术语。

**信号**：
- CellChat 图注"健康/疾病"标签≠实际分组
- SHAP 蜂群图注残留"死亡风险"（来自生存分析模板）
- DCA 图注残留"不同时间结局"（Cox 回归模板语言）
- 临床统计报告混入 `生存时间`, `hazard ratio` 等生存分析术语

**检测**：高风险章节专项搜索：
- CellChat → 搜索分组关键词
- SHAP → 搜索 `死亡|survival|hazard`
- DCA → 搜索 `时间尺度|不同时间`

**案例**：26YSH015F 的 SHAP 图注残留"死亡风险"（本项目为胎盘植入，无生存分析）

---

## 综合检测策略

```
1. 自动检测（Round 0）:
   - check_project_id_consistency.py → P01
   - check_term_consistency.py → P02
   
2. 覆盖矩阵阶段:
   - GSE 编号交叉验证 → P03
   - 路径引用存在性验证 → P03

3. Layer 2 视觉审核:
   - 图件标题疾病名核对 → P02
   - 图注术语与项目匹配 → P12

4. Layer 3 Sub-Agent:
   - 全文术语扫描 → P02, P12
   - 报告-代码路径匹配 → P03
```
