# 模式：图件与视觉审核错误

> 严重性：🟠 MAJOR ～ 🔴 CRITICAL
> 涉及项目：26YYS083F, 26YHB147F, 25YYF085F, 26YHB100F, 26YHB087F

---

## P08: 图件编号/内容错误

**描述**：Figure 编号不连续、引用越界、图注矛盾、跨项目图件复用。

**信号**：
- 章节编号跳号（2.7→2.9 缺 2.8）
- 引用不存在的 Figure（引用 "Figure 3E" 但对应内容在 Figure 19）
- 图注前后矛盾（标题"脓毒症"但描述"健康状态"）
- CellChat "数量" vs "强度"标签错配
- 同一张图被复用为"QC 前"和"QC 后"

**检测**：
```
1. 提取报告全部 Figure 引用编号 → 检查连续性、不越界
2. 逐模块核对 Figure 物理文件名 vs 报告引用
3. Layer 2 视觉审核逐图核对标题/图注
```

**案例**：26YYS083F — "如Figure 3E所示"但 2.16.2 节应引用 Figure 19E

---

## P17: 单细胞 QC 报告视觉错误

**描述**：单细胞数据 QC 图件特有——前后图混淆、降维方法错 、分组标签残留。

**信号**：
- QC 前后图是同一张（错误复用）
- 降维方法名称写错（t-SNE vs UMAP 混用）
- 分组标签残留（Sham/MCAO vs Control/NAFLD）
- 细胞类型翻译错误（Platelets→"血细胞"应为"血小板"）

**检测**：
```
1. Layer 2 视觉审核: 逐图对照 QC 前后是否为不同图
2. 标签核验: 降维方法名与代码参数一致
3. 翻译核验: 细胞类型中英文对照表
```

**案例**：26YHB100F — QC 前后图被复用为同一张

---

## 综合检测策略

```
1. 自动检测 (Round 0):
   - check_figure_integrity.py → 文件存在性/大小（非内容）
   - check_number_crossref.py → Figure 编号连续性

2. Layer 2 全量视觉审核 (Round 1):
   - 逐图标题/疾病名核对 → P08
   - QC 前后图差异验证 → P17
   - 图注-正文匹配 → P08
   - cell type 翻译核对 → P17

3. Layer 4 最终复核:
   - 回溯验证 Layer 2 发现的高等级问题
```
