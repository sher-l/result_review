# 模式：数据流断裂与覆盖缺失

> 严重性：🔴 FATAL (P06) / 🟠 MAJOR (P11)

## P06: 数据流断裂

**描述**：下游分析的输入与上游分析的输出不一致，数据传递链条断裂。

**信号**：
- 下游输入基因数 < 上游输出基因数（如 monocle 用 3 个基因但交集有 19 个）
- 路径的输入≠上游输出，且无说明
- 多数据集间验证集与训练集基因不一致

**检测**：
```
验证数据流链条：
上游输出文件（如 CandiGenes.csv 行数）
  = 下游输入（如 monocle.R 中特征个数）
  = 报告声称的基因数量
```

**案例**：25YLC105F — monocle 仅用 3 个基因但上游交集有 19 个，无缩减解释

---

## P07: 基因名笔误/物种不匹配

**描述**：正文基因名与结果 CSV 不一致；人/鼠物种标注错误。

**信号**：
- 基因名笔误（CXX1 vs CXXC1）
- 人类数据用 `org.Mm.eg.db`（小鼠注释库）
- `hsa` vs `mmu` 前缀混用
- M6A 标准基因集缺失（应 25 个，实际 24 个）

**检测**：正文基因名 ↔ CSV 交叉验证 + 物种前缀检查

**案例**：26YYS083F — 写"CXX1"应为"CXXC1"（少一个C）

---

## P11: 覆盖矩阵双向不一致

**描述**：报告正文与结果文件的对应关系不完整——有结果无报告或有报告无结果。

**信号**：
- 结果目录有完整模块但正文无对应章节
- 正文提到的数据集未在 Table 1 声明
- GSE 编号在结果目录中无对应文件

**检测**：
```
双向覆盖矩阵：
方向 1: 结果目录每个子文件夹 → 报告是否覆盖？
方向 2: 报告每个分析声称 → 结果目录是否有文件支撑？
方向 3: 报告 GSE 编号 → Table 1 是否声明？
```

**案例**：25YYF085F — 正文出现 GSE65682 但未在 Table 1 数据集列表中声明
