# 26YSH045F 可复用审核经验

1. **方案也必须纳入身份闭合。** 方案编号或数据集与报告/结果不一致时，不能把它当作孤立的文书错误；没有变更记录即破坏项目可追溯性。
2. **单细胞疾病推断先查统计单位。** 细胞级 Wilcoxon、合并细胞比例和预选基因相关性不能替代 donor/sample 层级比较。
3. **评分名称必须反映实际基因集。** 将凋亡与焦亡混合后命名为焦亡评分，会使整个疾病机制主线失去特异性。
4. **高风险推断不能只交图。** CellChat 和轨迹结论必须交付结构化边表/统计/对象/敏感性，图件只可作为辅助展示。
5. **模板残留需做四联核对。** 逐章节比对数据集、分组、图号和结果目录，能快速发现外项目疾病术语、图号重复和路径主题互换。
