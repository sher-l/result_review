## 发现的问题

### 问题1：报告描述不精确（中等）

**问题描述**：
报告中说"计算线粒体自噬相关基因在**所有样本**的评分"，但实际上只使用了训练集GSE43292的64个样本，而非全部197个样本。

**报告原文**：
> "使用R包GSVA中的ssGSEA计算方法计算线粒体自噬相关基因在所有样本的评分"

**实际情况**：
- GSE43292 (训练集): 64 样本 ✅ 参与ssGSEA
- GSE100927 (验证集1): 104 样本 ❌ 未参与
- GSE28829 (验证集2): 29 样本 ❌ 未参与

**验证代码**：
```python
# r-02_Mitophagy.R 第10-11行
data <- fread("./01_DEGs/GSE43292.symbol.csv", ...)  # 只用了GSE43292
group <- fread("./01_DEGs/GSE43292.group.csv", ...)
```

**严重性**: 🟡 中等（描述不精确，容易产生误解）

**建议修改**：
> "计算线粒体自噬相关基因在**训练集GSE43292的所有样本**的评分"

## 框架优化建议

### 新增检查项：样本范围描述精确性

**背景**：
多数据集项目中，"所有样本"的描述容易产生歧义，需要明确说明是哪个数据集的样本。

**检查方法**：
1. 在报告中搜索"所有样本"、"全部样本"等表述
2. 对照代码确认实际使用的数据集
3. 验证样本数量是否匹配

**检查清单**：
```
□ 报告中"所有样本"/"全部样本"的描述是否精确？
□ 是否明确说明了使用的是哪个数据集？
□ 样本数量是否与实际使用的一致？
```

**常见问题模式**：
| 报告描述 | 实际情况 | 问题级别 |
|---------|---------|---------|
| "所有样本" | 只有训练集样本 | 🟡 中等 |
| "全部数据" | 部分数据集 | 🟡 中等 |
| "验证集" | 训练集+验证集 | 🔴 严重 |
