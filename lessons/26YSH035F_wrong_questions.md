## 错题 1：共定位阴性后不能直接延伸为核心因果链

- 典型错误：方法规定 PPH4>0.7 保留显著共定位基因，结果却显示无显著共定位，后续仍把 MR 基因作为核心关键基因基础。
- 触发场景：MR、共定位、DEG、机器学习串联项目。
- 证据 basis：final_review_report.md F-01；B01 与 C03 均确认。
- 正确标准：共定位阴性必须降低因果链证据强度，后续只能写探索性候选，除非补充其他强证据。
- 下次提醒：先查 coloc 表 PP.H4 和 is_significant，再看结论是否仍写因果或核心机制。
- 严重度：CRITICAL。
- 可执行规则建议：若正文出现“无显著共定位”且总结出现“核心关键基因”或“因果基因”，自动生成高风险 finding。

## 错题 2：MD 选择规则必须和结合能表、Dynamic 目录三者闭合

- 典型错误：方法写选择 2 对最高结合能复合物，结果却交付 3 个 Dynamic 对象且包含非前二对象。
- 触发场景：分子对接后接 GROMACS 或 MD 模拟。
- 证据 basis：final_review_report.md F-02；B01 与 C03 均确认。
- 正确标准：选择规则、排序表、模拟目录、正文对象必须一致；并列值要说明取舍。
- 下次提醒：读取结合能表后按绝对值排序，再对比 Dynamic 子目录。
- 严重度：MAJOR。
- 可执行规则建议：自动抽取结合能表 topN 与 Dynamic 目录名进行集合对比。

## 错题 3：代码不可复现不能单独升级，但与核心矛盾合并时必须进入退回依据

- 典型错误：只因 total_code_files=0 就作为唯一不通过理由，或反过来把缺代码当成普通提醒而忽略高风险模块。
- 触发场景：docx-only 交付，大量结果图表但无脚本。
- 证据 basis：final_review_report.md F-05；project_structure.json total_code_files=0。
- 正确标准：缺代码本身按框架为 WARNING 级风险；若叠加核心统计矛盾、对象选择错误或结论过度，应合并评价。
- 下次提醒：分开写“代码不可复现风险”和“实质证据链问题”。
- 严重度：MAJOR。
- 可执行规则建议：报告生成器强制输出缺代码单列说明，并检查是否与实质问题分开计级。

## 错题 4：只有图片不能支撑强模型性能和生存显著性

- 典型错误：报告写 AUC、校准、DCA、log-rank 显著，但交付只有图，没有结构化指标表。
- 触发场景：机器学习、列线图、生存分析模块。
- 证据 basis：final_review_report.md F-06、F-07；A02 与 C02 均确认。
- 正确标准：模型性能需有 AUC/CI/阈值/敏感性/特异性等表；生存分析需有 HR、CI、P 值或 log-rank 结果。
- 下次提醒：看到“显著”“AUC”“校准”即追结构化表和脚本。
- 严重度：MAJOR。
- 可执行规则建议：若正文含 AUC 或 log-rank P，而目录缺少对应 CSV/XLSX 统计表，自动列入 fact_check。

## 错题 5：预测和模拟结果不能写成机制已阐明或干预潜力已证实

- 典型错误：将 scTenifoldKnk 虚拟敲除、PheWAS-MR 或 MD 稳定性写成机制阐明、靶向干预潜力已证实。
- 触发场景：单细胞、虚拟敲除、PheWAS-MR、分子动力学模块。
- 证据 basis：final_review_report.md F-09、F-10；C03 专项确认。
- 正确标准：无实验验证和可复现命令时只能写“计算预测提示”或“探索性关联”。
- 下次提醒：高风险模块结论逐句查是否从计算结果跳到生物机制确认。
- 严重度：WARNING 至 MAJOR，视是否影响主结论升级。
- 可执行规则建议：识别“证实、阐明、干预潜力”等强词，与模块类型和证据强度交叉触发降级提醒。
