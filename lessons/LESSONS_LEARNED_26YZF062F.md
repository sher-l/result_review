# 26YZF062F 可复用学习条目

- 单细胞跨组和临床相关结论必须以供体/样本为独立单位；细胞级检验不能替代 pseudobulk 或含供体效应的模型。
- 高风险计算模块的结论必须同时具备输入、执行命令/参数、日志、结构化结果和可读图源；空目录或空白图位不能支撑“已验证”结论。
- DEG、候选基因和多模块交集必须核验 ID 读取、行名语义、去重与映射；自动行号进入 `intersect` 会使整条下游证据失效。
- MR 应以唯一暴露标识逐项运行敏感性检验并进行预定义多重校正；共定位必须使用真实数据集级样本量，且公式、输出和正文应可相互复算。
- 视觉审核需分开记录覆盖守恒和内容 finding：若合并遗漏资产，应保留失败事件、执行最小补审并重跑合并；覆盖通过不能抹除全黑图、图文错配或无关宣传材料。

适用：相似转录组、单细胞、MR、共定位和计算药理报告的优先复核项；仍须根据当前项目证据独立裁定。
