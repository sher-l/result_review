# 26YTY086F 错题集

> **项目编号**：26YTY086F  
> **目的**：沉淀本轮可复用的审核触发条件；不替代本项目未决事项清单。

## W-001：报告筛选阈值与结构化结果表未逐行核验

| 字段 | 内容 |
|---|---|
| **典型错误** | 报告称按 `p_SMR<0.05` 且 `p_HEIDI>0.05` 得到 93 基因，但结果表不满足。 |
| **触发场景** | 报告将筛选后的基因/特征作为所有下游分析的核心输入。 |
| **证据依据** | `SMR_result_need.xlsx` 93 行仅 3 行满足；`report_text.txt` L21/L44；`SMR.r` 未实现 HEIDI 筛选。 |
| **正确标准** | 对“筛选后 N 项”逐行复算报告规则，并检查代码是否实现全部阈值、校正和排除条件。 |
| **下次审核提醒** | 优先核对核心输入集，不能只看火山图或结果文件存在。 |
| **严重程度** | CRITICAL |
| **可执行规则建议** | 若报告声明筛选规则与结构化表满足数差异超过 0，自动列为高风险；若其为后续输入则进入 CRITICAL 仲裁队列。 |

## W-002：外部验证数据集声明、交付目录和脚本输入未闭环

| 字段 | 内容 |
|---|---|
| **典型错误** | 报告 GSE43490 与样本量，主数据目录却缺该数据且出现未声明 GSE49036；脚本输入也缺失。 |
| **触发场景** | 报告将某队列称为训练/验证集，且关键基因或模型结论依赖该队列。 |
| **证据依据** | 主 0-数据目录、`expression.R` 输入名、`case_manifest.json` 与收敛项 `C02-STAT-001`。 |
| **正确标准** | 报告数据集 ID、样本量、分组标签、物理文件、代码路径必须一一可追溯且兼容。 |
| **下次审核提醒** | 附件中的同名数据不能自动补足主报告指定交付位置。 |
| **严重程度** | CRITICAL |
| **可执行规则建议** | 对报告每个 GSE ID 建立“报告—目录—代码—分组—样本量”五列闭环；任一缺失即阻断外部验证主张。 |

## W-003：高风险候选药物链只有展示性文件

| 字段 | 内容 |
|---|---|
| **典型错误** | 两份基因命名 DrugReflector CSV 完全相同，无输入/参数；对接、MD 无原始资产或数值。 |
| **触发场景** | 虚拟筛选、对接、MD 用于推出候选药物或稳定性。 |
| **证据依据** | 两个 200 行 CSV SHA-256 相同；8-模块仅表/PDF；9-模块仅 9 PDF；`convergence_report.json` 高风险摘要。 |
| **正确标准** | 虚拟筛选需输入/参数/排序记录；对接需受体、配体、score、pose；MD 需轨迹/原始输出、时长、数值序列与系统身份。 |
| **下次审核提醒** | 图和单行/两行数值仅能支持展示，不可替代可复现证据链。 |
| **严重程度** | CRITICAL |
| **可执行规则建议** | 对三类高风险模块按最小证据包逐项门禁；缺包且支撑核心候选结论时，进入高风险仲裁。 |

## W-004：关键基因筛选只交图件、模型选择使用后验验证

| 字段 | 内容 |
|---|---|
| **典型错误** | 只有箱线图星号，无 p 值/效应量/多重校正/ROC；LASSO 因“保留随后验证成功基因”被选中。 |
| **触发场景** | 小样本高维机器学习、跨队列关键基因验证、诊断标志物声称。 |
| **证据依据** | `expression.R`、关键基因模块两 PDF、Agent C `C02-STAT-002`–`005`。 |
| **正确标准** | 预定义算法选择，提供重采样稳定性、性能导出和全部统计检验/校正；验证集不得反向选择算法。 |
| **下次审核提醒** | “显著星号”和“诊断标志物”之间必须有可审计统计与性能表。 |
| **严重程度** | MAJOR |
| **可执行规则建议** | 关键基因/诊断模块缺 p 值、效应量、校正或 ROC/AUC 任一项时标记 MAJOR；检测到后验选模文本时增加统计复核。 |

## W-005：图号、规则文字与代码不一致

| 字段 | 内容 |
|---|---|
| **典型错误** | PPI 的图3C与图注图2C冲突；GSEA 的阈值/排序与脚本不一致。 |
| **触发场景** | 多模块报告、多图组合、方法段含多阈值或排序。 |
| **证据依据** | MC-013、`report_text.txt` L50–L61、`GSEA_循环.R` L113–L126。 |
| **正确标准** | 每个图号唯一；书面规则必须被代码完整实现，或明确说明差异。 |
| **下次审核提醒** | 机械重复图号须 AI复核定性；代码只实现部分规则不可因当前结果未受影响而忽略。 |
| **严重程度** | MAJOR/WARNING（按对核心结论的影响） |
| **可执行规则建议** | 图号唯一性和代码—方法阈值/排序比对纳入预检候选项并要求 AI处置。 |
