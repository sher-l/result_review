# 26YZF067F 可复用审核经验

- ML模型若先在全量数据上筛特征，再拆分训练/验证，应按数据泄漏高风险处理；验证集AUC不能作为独立验证证据。
- 药物警戒项目删除VigiBase/ADC等范围后，必须同步清理标题、方法和总结，不能只在正文注释说明删除。
- SHAP、KM/Kruskal-Wallis、Weibull和贝叶斯逻辑回归属于高风险统计/解释模块，只有图片或汇总OR不足以支撑强结论。
- FAERS TTO/Weibull应限定为报告时间分布，缺少真实随访分母时避免“发生率/风险时间”外推。
- 当Python xlsx依赖缺失时，可用xlsx zip XML直读核对关键单元格，作为框架备用路径。
