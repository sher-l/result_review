# 26YYH131F 可复用审核教训

- 对含特征 ID 首列的表格，必须核验读入参数、行名保留和下游键使用；脚本存在不代表数据流正确。
- 富集本体、方向性、阈值和图文中的可计数声明，都应做“报告—代码—结果表—图例”交叉映射。
- 单细胞关键步骤不能仅提供 PDF；应交付参数、对象/表格摘要和结构化中间结果。
- GraphBAN、对接、MD、虚拟敲除等高风险模块须提供端到端 manifest；局部图表不能替代复现链。
- 机器学习筛选须分开核验输入库规模、性能/校准和阈值依据，缺失时不得使用“高置信”措辞。
- 预测、模拟、内部一致性与独立验证应使用不同结论强度；未满足数据独立性和统计门槛时不得称为验证、证明或保守。
- 机械字符串命中只作为候选：CytoTRACE、SCENIC 等必须以实际执行证据确认，避免把引用或映射误报为缺陷。
