# 26YBB086F 错题集

## 错题 1：核心预后图外癌种残留
- 错误类型：copy-paste/外项目图文残留。
- 具体表现：PAAD 项目核心 Cox 图文出现“结直肠癌患者”和“LUAD Hazard Ratio”。
- 触发场景：预后模型森林图、图注和正文从旧项目复制后未替换。
- 证据依据：B02-F001；final report F-01。
- 正确标准：核心图件标题、轴标签、正文疾病名必须与当前项目完全一致。
- 下次审核提醒：预后图先查癌种缩写、疾病中文名和横轴标题。
- 严重程度：FATAL。
- 可执行规则建议：若核心模型图中出现非当前疾病/癌种缩写，直接进入退回项。

## 错题 2：未声明 GEO 进入主流程
- 错误类型：数据来源声明与代码输入不一致。
- 具体表现：GSE212966 进入 scRNA；GSE21501/GSE62452/GSE71729 进入 101ML/common_genes。
- 触发场景：复用代码或保留额外验证队列但报告数据来源未披露。
- 证据依据：A01/B03/C02 多切片；final report F-02/F-03。
- 正确标准：所有参与上游输入、交集、模型训练/验证的数据集必须在数据来源和方法中披露。
- 下次审核提醒：反向扫描全部 GSE 编号，区分“代码注释残留”和“实际参与对象/文件名/交集”。
- 严重程度：CRITICAL。
- 可执行规则建议：`geo_references` 多出未声明 GSE 且出现在代码读取/对象名时自动升级。

## 错题 3：101ML 最佳模型无结构化排序证据
- 错误类型：机器学习模型选择证据不足。
- 具体表现：仅有 C-index PDF 热图，缺完整矩阵；代码直接设定 best_model；性能方向翻转未披露。
- 触发场景：101ML/StepCox/Lasso 自动建模结果只交付图片。
- 证据依据：A02B/c02a；final report F-04。
- 正确标准：交付完整模型性能矩阵、排序规则、事件编码和方向处理标记。
- 下次审核提醒：不要接受“平均最高”的口头结论，必须追矩阵和排序代码。
- 严重程度：CRITICAL。
- 可执行规则建议：ML 模型选择若缺矩阵或 hard-code best_model，至少 MAJOR，若影响核心结论则 CRITICAL。

## 错题 4：高风险动态/空间模块只交付 PDF 或依赖本机对象
- 错误类型：高风险模块不可复现。
- 具体表现：scTenifoldKnk、MISTy、Squidiff 等缺 Rdata/H5AD/checkpoint/helper。
- 触发场景：高风险机制模块使用外部 wrapper、本机路径或 notebook 片段。
- 证据依据：C03 与 C01 blockers；final report F-06/F-07。
- 正确标准：高风险模块必须提供输入对象、参数、脚本、版本、关键结构化输出。
- 下次审核提醒：PDF 图不能替代模型对象和统计表。
- 严重程度：CRITICAL。
- 可执行规则建议：高风险模块缺复现对象时，在覆盖矩阵中单列 proof gap。
