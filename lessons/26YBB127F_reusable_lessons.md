# 26YBB127F 可复用审核教训

- **数据谱系**：从脚本抽取数据集 accession，与报告声明数据表做差集；每个差集必须说明用途、保留/排除与输出链接。
- **可复现矩阵**：逐模块记录结果、生成脚本、参数、环境和运行日志；结果文件存在不等于生成链路可复现。
- **参数三向比对**：报告阈值、config、临界输出须一致；不一致时不能猜测真实运行值，必须索取日志。
- **图件范围**：单细胞分面图应核对可见面板数、图注样本数、绘图时点与样本 ID 映射。
- **双方法判定**：需要可联接逐细胞的各方法 score/call 及 agreement 表，而非仅图件或目录。
- **模型证据分级**：训练表观性能、内验证、外部验证、AUC CI 和 ROC 点应分别交付、分别表述。
- **自动规则闸门**：相近术语（ssGSEA/GSEA）和图号解析仅作候选，必须经文件或视觉审核再定性。
