# 26YYH130F 可复用审核教训

- 报告、代码和交付目录中的数据集集合必须做三方差集核验；未声明 GEO 引用属于 MAJOR。
- 统计阈值必须从脚本、结果表和报告中做可解析比对；禁止以 `p.value` 替代 FDR，也要拦截损坏的科学计数法。
- ML/列线图的可泛化主张至少需要固定参数、实际独立验证、逐样本预测与 ROC/校准/DCA 数值表。
- 对接、MD、Geneformer 的结果图不能代替可复现证据；应分别核验输入、参数、日志、原始序列/权重和脚本。
- 单细胞比较须证明独立样本处理，避免把细胞数量当作重复数。
- 视觉发布门禁应要求：预筛告警全部关闭、资产计数守恒、高风险图提供坐标/矩阵/预测表来源。
- 跨路收敛应使用模块、主张、数据集与证据路径组成的语义指纹；零共识率时必须进行保守人工裁定。
