## WQ-001：声明空间数据集但未交付可追溯源数据和实现

| 项目 | 内容 |
|---|---|
| 典型错误 | 只交付空间派生表，却未交付/登记声明的 GSE283052 源数据，也未交付空间实现代码。 |
| 触发场景 | 报告含空间转录组、RCTD、空间通讯或多切片结论。 |
| 证据依据 | `arbitration_decisions.json`：`ARB-SPATIAL-001`；报告 L13/L18/L138–L177；`00_rawdata` 目录与脚本清单。 |
| 正确标准 | 数据集声明、rawdata/manifest、样本映射、实现代码、运行记录和派生表必须闭环。 |
| 下次提醒 | 先做“报告 GEO 清单 × rawdata × 代码引用”三向比对，再审空间图表。 |
| 严重度 | CRITICAL |
| 可执行规则建议 | 若空间数据集未在 rawdata 或可验证 manifest 中出现，且空间代码缺失，则合并判 CRITICAL，禁止以派生表替代源数据闭环。 |

## WQ-002：将单细胞当独立样本并以原始 p 宣称显著

| 项目 | 内容 |
|---|---|
| 典型错误 | 对细胞级表达直接 Wilcoxon，未按样本聚合；已算 BH 后仍以原始 p 标星。 |
| 触发场景 | 单细胞组间差异、关键细胞/基因筛选、图中显著性标签。 |
| 证据依据 | `agent_c_result.json`：c02-F001、c02-F002；`r.07_scRNA.Hubgene.Exp.R L112-L160`。 |
| 正确标准 | 生物学样本是推断单位；采用 pseudobulk、样本级汇总或混合模型；显著性结论以预定义校正范围内的 p_adj/FDR 为准。 |
| 下次提醒 | 抽查结果表的 n 是否为细胞数；比对 `significance` 列与 `p_adj`。 |
| 严重度 | MAJOR |
| 可执行规则建议 | 检出 `wilcox.test(expr ~ Group)` 且 n 为细胞数时强制统计复核；若有 p_adj 但显著性依赖 p_value，自动提升为高风险。 |

## WQ-003：方法/结果未完成却以已完成分析写入报告

| 项目 | 内容 |
|---|---|
| 典型错误 | MR/SMR 写入研究方向和方法，但无结果、输入或代码；同时方法公式和阈值错误。 |
| 触发场景 | 报告有“尚未完成”“待取得数据”字样，同时仍将模块列为研究完成范围。 |
| 证据依据 | `agent_a_result.json` a01-F002/a02-F002；`agent_b_result.json` B01-002/B01-003；报告 L38–L40、L178–L180。 |
| 正确标准 | 未完成模块必须隔离为计划工作；完成模块必须有输入、脚本、结果和可复核阈值。 |
| 下次提醒 | 对每个方法章节检查同名结果目录、输入、脚本与结果表；核验统计公式和多重校正。 |
| 严重度 | MAJOR |
| 可执行规则建议 | 对“尚未完成”章节自动要求范围标注；若方法公式或 Bonferroni 阈值不自洽，生成独立事实核对项。 |
